# Sistema de Gestión de Inventario para una Tienda

## Descripción

Este proyecto fue desarrollado con Angular y TypeScript. Permite registrar, visualizar, editar y eliminar productos de una tienda, además de consultar el estado del stock.

## Tecnologías

- Angular 17
- TypeScript
- Bootstrap 5
- HTML
- CSS

## Funcionalidades

- Registrar productos.
- Visualizar productos.
- Editar productos.
- Eliminar productos.
- Consultar el estado del stock.
- Registrar entradas y salidas de inventario.

## Instalación

1. Clonar el repositorio.

```bash
git clone https://github.com/karmatacos/inventario-tienda.git
```

2. Entrar a la carpeta del proyecto.

```bash
cd inventario-tienda
```

3. Instalar las dependencias.

```bash
npm install
```

4. Ejecutar la aplicación.

```bash
ng serve
```

5. Abrir el navegador en:

```text
http://localhost:4200
```

## Estructura básica

- `nucleo`: modelos y servicios.
- `funcionalidades`: pantallas principales del sistema.
- `compartido`: componentes reutilizables, pipes y directivas.
